# Code of Conduct

This repository welcomes corrections, questions, and proposed examples
from anyone. Keep discussion focused on the content: is a claim accurate,
is an example clear, does a section belong here. Disagree with the
reasoning, not the person, and assume good faith from other participants.

Harassment, personal attacks, and off-topic discussion aren't welcome
here. Reports can go to the email address on the maintainer's GitHub
profile.
